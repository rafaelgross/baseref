Long description
PRISMA-SLR is a free and open-source web application that supports researchers in conducting systematic literature reviews (SLR) following the PRISMA 2020 (Preferred Reporting Items for Systematic Reviews and Meta-Analyses) protocol. It provides a complete workflow: importing references from Scopus and Web of Science (.bib files), automatic duplicate detection, title/abstract screening, full-text eligibility assessment, automatic PRISMA 2020 flow diagram generation, bibliometric analysis with 12 chart types, co-authorship and keyword co-occurrence networks, and export to CSV, BibTeX, and JSON. The system runs on any PHP 8+ + MySQL server and requires no proprietary dependencies.

Software Description

PRISMA-SLR is an open-source web system for managing Systematic Literature Reviews (SLR). It implements the complete PRISMA 2020 workflow — from importing references to generating the final flow diagram and bibliometric analysis — in a single, self-hosted application with no vendor lock-in.

Purpose

Conducting a systematic literature review requires tracking hundreds of articles through multiple screening phases while maintaining a precise audit trail. Most researchers rely on proprietary tools (Rayyan, Covidence, Parsifal) that impose usage limits, fees, and data lock-in. PRISMA-SLR provides all essential functionality as free software, deployable on any PHP/MySQL server.

Interface Screenshots (Description)

The following screens are available in the application:

#ScreenDescription
1 Dashboard / Projects Project list with statistics (total articles, duplicates, included). Dark modern theme with sidebar navigation.
2 BibTeX Import Drag-and-drop import interface with progress indicator and automatic source type detection (Scopus / Web of Science).
3 Duplicate Detection Side-by-side article comparison with similarity score and batch confirmation controls.
4 Screening (Triagem) Article list with title/abstract, include/exclude/uncertain buttons, configurable exclusion reasons, star rating, and notes. Supports table view and abstract modal view.
5 PRISMA 2020 Flow Diagram Auto-generated SVG diagram following the PRISMA 2020 standard. Shows identification, screening, eligibility, and inclusion counts with exportable PNG/SVG.
6 Bibliometrics Dashboard with 11+ charts: publications/year, top journals, top authors, country choropleth map, co-authorship network, keyword co-occurrence network, word cloud, and more.
7 PRISMA 2020 Checklist 27-item interactive checklist for verifying report compliance. Tracks completion per item with yes/partial/no responses and page references.
8 Export Export to CSV, BibTeX, and JSON for all articles, included only, or any filtered subset.
